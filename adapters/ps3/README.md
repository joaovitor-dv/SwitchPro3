# PS3 adapter

This directory is reserved for the future VSH SPRX adapter. It will own:

- exact `057e:2009` USB matching;
- bounded `cellUsbd` attach, transfer and detach handling;
- translation from `sp3_input_state` to the PS3 virtual-pad representation;
- console-specific logging and recovery-safe configuration.

No Sony SDK files, signing material, firmware payloads or prebuilt binaries are
stored here.
