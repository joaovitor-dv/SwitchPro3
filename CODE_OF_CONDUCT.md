# Code of Conduct

We want SwitchPro3 to be a respectful place to learn, test and build.

- Be patient and constructive; criticize the work, not the person.
- State uncertainty and accept evidence-based corrections.
- Never publish another person's data, and redact sensitive details from logs.
- Harassment, discrimination, personal attacks, doxxing and sexualized conduct
  are not acceptable.

This applies to issues, Pull Requests, discussions and other project spaces.
Maintainers may remove content or block participation that violates it. Private
reports may be sent through GitHub Security reporting or the repository owner's
GitHub profile.
